# 🌐 Personal Introduction Page

A simple and beginner-friendly **Personal Introduction Website** built using **HTML5 and CSS3**. This project is designed to practice basic HTML elements, CSS selectors, spacing, colors, typography, and page layout.

## 📌 Project Overview

The website introduces a person through a clean single-page layout containing:

* 👤 Profile image
* 🙋 About Me section
* 🛠️ Skills section
* 🎯 Hobbies section
* 📧 Contact information
* 📱 Responsive design for smaller screens

## 🎯 Objective

The main objective of this project is to practice:

* HTML5 structure
* CSS3 styling
* CSS selectors
* Typography
* Colors and backgrounds
* Margins and padding
* Lists
* Simple responsive design
* Basic webpage layout

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## ✨ Features

### About

A short introduction about the person.

### Skills

A list of technical and personal skills.

### Hobbies

A list of personal interests and hobbies.

### Contact

Basic contact information such as email, phone number, and location.

### Responsive Design

The webpage includes a simple media query to make the layout more suitable for mobile devices.

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/tommyvercity90/personal-introduction-page.git
```

2. Open the project folder.

3. Open `index.html` in any modern web browser.

That's it! 🎉

## 🖼️ Customization

You can personalize the webpage by changing:

* Your name
* Profile picture
* About Me description
* Skills
* Hobbies
* Email address
* Phone number
* Location
* Colors and fonts

For example, replace:

```html
<h1>Your Name</h1>
```

with:

```html
<h1>Aryan Thakur</h1>
```

You can also replace the placeholder profile image with your own image.
